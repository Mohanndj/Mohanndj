# مهامي

تطبيق لتجميع مهامك وأهدافك اليومية، يعمل على الجوال والكمبيوتر، ويمكن تثبيته على الشاشة الرئيسية ليعمل كتطبيق مستقل حتى دون إنترنت.

## المزايا
- **المساعد الذكي:** اكتب بكلامك العادي، مثل «ذكرني أتصل بأبوي بكرة الساعة 5 العصر وقبلها بربع ساعة» أو «اشرب 8 أكواب ماء كل يوم لمدة شهر»، فيفهم التاريخ والوقت والتكرار والصلاة والأولوية والتصنيف (#عمل)، ويعرض ما فهمه قبل الإضافة. يعمل على الجهاز دون إنترنت.
- **اليوم:** كل ما يخصّ يومك في شاشة واحدة، مع دائرة تقدّم وأوقات الصلاة والتاريخ الهجري.
- **المهام:** أولوية وتصنيف وتاريخ، مع بحث يشمل الخطوات والملاحظات.
- **التقويم الشهري:** يبدأ الأسبوع بالسبت، مع الشهر الهجري ونقاط ملونة لمهام كل يوم. اضغط أي يوم لترى مهامه أو تضيف له مهمة.
- **الأهداف المتكررة:** يومياً أو أيام الدوام أو أيام تختارها، إلى تاريخ محدد أو بلا نهاية. ويمكن أن يكون الهدف بعدد، مثل 8 أكواب ماء، تزيده خطوة خطوة.
- **الخطوات:** قسّم المهمة الكبيرة إلى خطوات صغيرة تعلّمها واحدة واحدة.
- **ملاحظات بلا حد:** لكل ملاحظة تاريخها ووقتها.
- **أوقات الصلاة:** تُحسب على الجهاز حسب مدينتك أو موقعك وطريقة الحساب (أم القرى وغيرها)، ويمكن ربط أي مهمة بها، مثل «بعد العصر بنصف ساعة».
- **منبهات دقيقة:** في الموعد أو قبله بـ 5 أو 10 أو 15 أو 30 دقيقة، أو ساعة أو ساعتين أو يوم، وأكثر من منبه للمهمة الواحدة، مع «تمت» و«غفوة 10 دقائق». ولضمان الرنين والتطبيق مغلق، زر «إضافة إلى تقويم الجوال» يضيف الموعد ومنبهاته إلى تقويمك.
- **الإحصائيات:** المنجز اليوم وآخر 7 أيام والإجمالي، والأيام المتتالية، ورسم لآخر 14 يوماً، وتوزيع حسب التصنيف، والتزامك بكل هدف.
- **التخصيص** (زر الترس أعلى الشاشة): اسمك، ولون التطبيق، والوضع الفاتح أو الداكن، وحجم الخط.
- **نسخة احتياطية:** تصدير البيانات واستيرادها كملف.

البيانات محفوظة على جهازك فقط (localStorage)، والمهام من النسخة الأولى تنتقل تلقائياً.

## التشغيل والتثبيت
التطبيق ملفات ثابتة، فيكفي نشرها على أي استضافة HTTPS. الأسهل GitHub Pages:

1. في المستودع: **Settings ← Pages**.
2. في **Source** اختر **Deploy from a branch**، ثم الفرع والمجلد `/ (root)`، واضغط **Save**.
3. بعد دقيقة يظهر الرابط، مثل `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.
4. افتح الرابط من الجوال:
   - **آيفون:** Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.
   - **أندرويد:** Chrome ← ⋮ ← **تثبيت التطبيق**، أو زر «تثبيت التطبيق» أعلى الصفحة.
5. من «التخصيص» (زر الترس) اختر مدينتك، ثم اضغط **تفعيل الإشعارات** ثم **تجربة المنبه**.

> على آيفون، الإشعارات تعمل فقط بعد تثبيت التطبيق على الشاشة الرئيسية (iOS 16.4 وأحدث).

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الواجهة |
| `styles.css` | التصميم والألوان والوضع الداكن |
| `app.js` | المنطق: المهام والأهداف والتقويم والمنبهات والإحصائيات |
| `nlp.js` | المساعد الذكي: فهم الجمل العربية |
| `prayer.js` | حساب أوقات الصلاة |
| `sw.js` | العمل دون إنترنت وأزرار الإشعارات |
| `manifest.webmanifest` و `icons/` | بيانات التثبيت والأيقونات |
