# مهامي

واجهة بسيطة لتجميع المهام وإدارتها، تعمل مباشرة في المتصفح دون أي تثبيت.

## المزايا
- إضافة مهام مع الأولوية (عالية / متوسطة / منخفضة) والتصنيف وتاريخ الاستحقاق
- تعليم المهام كمنجزة، تعديلها وحذفها
- بحث، وتصفية (الكل / الحالية / المنجزة)، وترتيب (الأحدث / التاريخ / الأولوية)
- إحصائيات وشريط تقدم، وتمييز المهام المتأخرة
- حفظ تلقائي في المتصفح (localStorage)
- دعم الوضع الليلي والشاشات الصغيرة

## التشغيل
افتح الملف `index.html` في أي متصفح.
