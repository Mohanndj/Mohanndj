# مهامي

تطبيق لتجميع مهامك وأهدافك اليومية، يعمل على الجوال والكمبيوتر، ويمكن تثبيته على الشاشة الرئيسية ليعمل كتطبيق مستقل حتى دون إنترنت.

## المزايا
- **اليوم:** كل ما يخصّ يومك في شاشة واحدة، مع دائرة تقدّم وتمييز المتأخر.
- **المهام:** أولوية وتصنيف وتاريخ، مع بحث يشمل الملاحظات، وتصفية وترتيب.
- **الأهداف المتكررة:** يومياً أو في أيام تختارها، إلى تاريخ محدد أو بلا نهاية، مع السلسلة الحالية ونسبة الالتزام وآخر 7 أيام.
- **ملاحظات بلا حد:** أضف لأي مهمة ما تشاء من الملاحظات، ولكل ملاحظة وقتها.
- **منبه:** صوت واهتزاز وإشعار في وقت المهمة، مع «تمت» و«غفوة 10 دقائق». ولضمان الرنين والتطبيق مغلق، زر «إضافة إلى تقويم الجوال» يضيف الموعد ومنبهه (والتكرار) إلى تقويمك.
- **الإحصائيات:** المنجز اليوم وآخر 7 أيام والإجمالي، والأيام المتتالية، ورسم لآخر 14 يوماً، وتوزيع حسب التصنيف، والتزامك بكل هدف.
- **التخصيص:** اسمك في التحية، ولون التطبيق، والوضع الفاتح أو الداكن، وحجم الخط.
- **نسخة احتياطية:** تصدير البيانات واستيرادها كملف.

البيانات محفوظة على جهازك فقط (localStorage)، والمهام من النسخة الأولى تنتقل تلقائياً.

## التشغيل والتثبيت
التطبيق ملفات ثابتة، فيكفي نشرها على أي استضافة HTTPS. الأسهل GitHub Pages:

1. في المستودع: **Settings ← Pages**.
2. في **Source** اختر **Deploy from a branch**، ثم الفرع والمجلد `/ (root)`، واضغط **Save**.
3. بعد دقيقة يظهر الرابط، مثل `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.
4. افتح الرابط من الجوال:
   - **آيفون:** Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.
   - **أندرويد:** Chrome ← ⋮ ← **تثبيت التطبيق**، أو زر «تثبيت التطبيق» أعلى الصفحة.
5. من «التخصيص» اضغط **تفعيل الإشعارات** ثم **تجربة المنبه**.

> على آيفون، الإشعارات تعمل فقط بعد تثبيت التطبيق على الشاشة الرئيسية (iOS 16.4 وأحدث).

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الواجهة |
| `styles.css` | التصميم والألوان والوضع الداكن |
| `app.js` | المنطق: المهام والأهداف والمنبهات والإحصائيات |
| `sw.js` | العمل دون إنترنت وأزرار الإشعارات |
| `manifest.webmanifest` و `icons/` | بيانات التثبيت والأيقونات |
